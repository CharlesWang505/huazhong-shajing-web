# 画中杀境

单文件卡牌试炼与关卡辅助工具。包含九境战役、选牌伤害预览、增益与墨市、牌组调整、概率参谋，以及可选的截图识别。

- **在线使用：** https://charleswang505.github.io/huazhong-shajing-web/
- **详细图文手册：** [docs/操作手册.md](docs/操作手册.md)
- **源文件：** [index.html](index.html)

![画中杀境首页](docs/images/01-home.png)

## 开始使用

1. 打开在线地址，选择「关卡试炼」在网页内游玩，或选择「关卡辅助」为外部游戏手动同步牌面并获取建议。
2. 离线使用：点击本仓库的 **Code → Download ZIP**，解压后用浏览器打开 `index.html`。基础试炼、手动录牌和本地推演不需要 API。
3. 需要识别截图时，再配置支持图像输入和浏览器 CORS 的 API。不要将真实密钥写进 HTML、仓库或截图。

## 两种模式

| 模式 | 用途 | 数据来源 |
| --- | --- | --- |
| 关卡试炼 | 在网页内挑战战役，结算伤害、墨卷与购买 | 网页内生成的牌局 |
| 关卡辅助 | 比较出牌、弃牌、墨市和调牌方案 | 用户录入或识别后核对的外部游戏状态 |

关卡辅助不是游戏自动操作器。「采用」只更新本工具的推演状态，不会替你在外部游戏中出牌或购买。

## 存档与隐私

- 进度保存在当前浏览器的 `localStorage`，没有云同步。不同设备、浏览器和站点来源的存档不互通。
- API 设置也保存在本机浏览器，其中密钥不是加密保险箱。不要在公共电脑保存长期密钥。
- 使用识别时，截图会由浏览器直接发送至你配置的 API 服务；使用手动录入无需发送截图。

## 项目结构

```text
index.html                 网页入口，原 HTML 的逐字节副本
.nojekyll                  GitHub Pages 静态发布标记
README.md                  项目入口
docs/操作手册.md            完整操作与发布维护说明
docs/images/               实机操作截图
```

无需构建、无需安装 Node.js、无需后端。GitHub Pages 使用 `main` 分支根目录发布；修改后提交到 `main`，等待 Pages 部署完成即可更新。
